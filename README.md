# Interactive Beam Analysis

A Streamlit educational web application for analyzing a simply supported beam.

## Features

- Sidebar-based beam configuration
- Multiple point loads
- Uniformly distributed loads
- Triangular and trapezoidal loads
- Applied concentrated moments
- CSV upload tab and downloadable template
- Free-body diagram
- Distributed-load plot
- Shear-force diagram
- Bending-moment diagram
- Elastic deflection diagram
- Rectangular, circular, and hollow rectangular sections
- Steel, aluminum, wood, concrete, and custom material options
- Equilibrium verification
- Simplified bending-stress and utilization check
- Step-by-step calculation tab
- CSV and text-result downloads

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy

Upload `app.py`, `requirements.txt`, and `README.md` to a public GitHub repository. Then deploy `app.py` through Streamlit Community Cloud.

## Important

This application is intended for education and preliminary analysis only. It is not a replacement for structural design codes or professional engineering review.
